E-commerce Sales Analysis

Project Overview

This project focuses on Exploratory Data Analysis (EDA) of e-commerce sales data using Python. It explores order information, product categories, sales amounts, and order statuses to identify useful patterns and insights.

Objectives

- Understand the dataset structure.
- Analyze sales across product categories.
- Explore order statuses and product quantities.
- Identify patterns using tables and visualizations.

Tools and Technologies

- Python
- Pandas
- Matplotlib
- Google Colab

Dataset

The dataset is a synthetic sample dataset created for practice and learning purposes. It does not contain real Amazon company data.

Key Insights

- Total Orders: 800
- Total Categories: 7
- Most Sold Category: Saree
- Highest Sales Category: Blouse
- Most Common Order Status: Shipped

These insights are based on the sample dataset.

Project Workflow

1. Load the dataset.
2. Inspect rows, columns, and data types.
3. Check for missing values.
4. Perform exploratory data analysis.
5. Create tables and visualizations.
6. Summarize the findings.
